Five full pages, desktop and mobile

Same homepage, five new worlds.

Airmail, a darkroom, a chart, a window, a cinema. Every direction is a working page, not a picture: hover the envelopes and trays, drag the tide and the sun, let the leader run once. Desktop sits beside mobile on each row, and each page reads fine with JavaScript off. Pick one whole, or point at the pieces worth merging.
